Trust the source, not the server.

A Firefox extension that blocks a dapp's code unless independent builders rebuilt it from the public source and got the same bytes.

Read the docs View on GitHub

The problem

In February 2025, Bybit lost about $1.5B. One file was tampered with on Safe{Wallet}'s hosting, while the GitHub repo stayed clean.

How it works

  1. Builders rebuild from public source

    Independent builders each rebuild the dapp from its public source, on their own machines or in their own GitHub organisation.

  2. They sign attestations to Arkiv

    Each builder signs what it got and publishes the attestation to Arkiv, under its own key.

  3. The extension hashes every file before it runs

    Anything that k builders didn't produce is blocked.

  4. Blocked sites get a verified copy

    The blocked page offers the verified copy from the mirror, so the dapp stays usable.

What it blocks

Swap
A tampered copy of one JS chunk is served, as at Bybit.
Inject
An extra third-party script is added to the page, as at BadgerDAO and KyberSwap.
Hijack
Every file comes from a cloned site with a modified bundle, as at Curve, Aerodrome and CoW Swap.
Config flip
A config value that looks valid is hostile, such as a flipped ipfsMode, and fails the curator's pins.

CROPS

Censorship resistance
If a site is taken down, the user can still open the verified copy on the mirror.
Open source
The code is MIT licensed, and every accepted release is rebuilt from public source.
Privacy
The extension syncs in bulk, with no lookups per site visit.
Security
Code is checked before it runs, and the check works without the dapp team.
